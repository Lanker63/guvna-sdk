# Proposals

Each mutation-capable agent (`semantic-compiler`, `realization-engineer`) records a proposal here before mutating a governed artifact, using the schema in [AGENT-OPERATING-MODEL.md §16](../../../doctrine/agentic/AGENT-OPERATING-MODEL.md).

A proposal filed here is not an approval. The corresponding decision belongs in [`../authority-ledger.yaml`](../authority-ledger.yaml), recorded only after an actual human decision.

Suggested filename: `<gate>-<short-slug>.yaml` (e.g. `gate-4-doctrine-agentic-baseline.yaml`).
