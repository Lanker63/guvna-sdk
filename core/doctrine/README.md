# README

The doctrine directory contains the accepted doctrine governing the Guvna Core, organized by doctrinal layer.

## Structure

- `constitution/` - constitutional doctrine
- `canonical/` - canonical models
- `architecture/` - architectural doctrine

Architecture doctrine index:

- `architecture/README.md` - architectural doctrine map and cross-doctrine traceability for conceptual, invariant, host-boundary, and Repository Adoption information-contract doctrine.

Canonical doctrine includes the repository's accepted semantic identity and filesystem realization conventions for authority-bearing governance artifacts.
