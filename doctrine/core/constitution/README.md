# Constitution Doctrine

This directory contains the accepted constitutional doctrine for Guvna Core.

Constitutional doctrine defines the immutable purpose and governing invariants that all downstream realizations must preserve.

## Doctrine Map

- [VISION.md](./VISION.md) - the governing vision for why Guvna exists and what durable repository understanding it seeks to preserve.
- [EPISTEMIC-INVARIANTS.md](./EPISTEMIC-INVARIANTS.md) - the constitutional invariants governing repository information, knowledge, intelligence, wisdom, authority, acceptance, provenance, and uncertainty.

## Cross-Doctrine Traceability

The vision establishes the enduring purpose of the doctrine.

The epistemic invariants establish the immutable laws that govern accepted repository understanding and all downstream realizations.

These artifacts are complementary and non-competing:

- `VISION.md` defines the purpose and direction of the doctrine.
- `EPISTEMIC-INVARIANTS.md` defines the constitutional rules that must remain intact.
